# Contributing

Thanks for wanting to add to the collection!

## Guidelines

1. **Free & no login** — Every resource must be free to access without signing up. No paywalls.
2. **Quality** — Only well-regarded, useful resources. No low-effort or spammy links.
3. **Format** — Use: `[Name](url) — One-line description.`
4. **Alphabetical** — Keep entries in alphabetical order within each category.
5. **One link per entry** — Point directly to the resource, not an aggregator.

## Adding a Resource

Open a PR adding the entry in the correct category section. Explain briefly what it is and why it belongs.
